关于我

点击返回 · click to return

我是 Peter Zhu（朱磊），在苏州做工程师。白天在 ECARX（吉利控股）里把推理和检索做成能上线的系统：模型要跑得稳，搜索在关键词和向量对不上的时候也要靠得住。

Most days go into production inference and retrieval at ECARX — serving models efficiently, and keeping search honest when keyword and vector signals disagree. I would rather talk about what shipped and what broke.

开源是正经工作的一部分。我给上游修过东西，也自己养了几个能直接跑的仓库：

  • deepinfer-hopper — Hopper / H200 inference
  • os-hybrid-kit — OpenSearch hybrid search (BM25 + kNN)
  • zvec-grep — local workspace search

Off the keyboard I lift, walk the hills around Suzhou, and cook for people I like feeding. No performance — just a life next to the work.

Recent projects

deepinfer-hopper

Python · CUDA

Inference engine adapted for NVIDIA H200 / Hopper (SM90) — tuned for real throughput on Hopper hardware, not a generic CUDA checkbox build.

os-hybrid-kit

Python · OpenSearch

Portable OpenSearch hybrid search: BM25 plus kNN, fused with RRF or weighted scores. Thin adapters so it drops into existing pipelines.

zvec-grep

Rust · CLI

Local-first search across a workspace — ripgrep-style text, BM25, and vector search behind one interface. Fork of zvec-ai/zvec-grep with ongoing work.
